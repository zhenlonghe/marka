# Marka

A small, fast Markdown editor for the Mac. It renders as you write, sets Chinese and English together the way a typesetter would, and opens in about a tenth of a second.

**Coming soon to the Mac App Store** · free to download · macOS 15.2 or later

## Live mode, or the source

Live mode renders everything except the block you are in, which opens up as plain Markdown. The text never jumps, and nothing hides in a preview pane. Press ⌘/ and the whole document turns back into source.

> This page is set the way Marka sets a document.
> Press ⌘/, or click any paragraph.

## Chinese and English, set together

  • - A quarter em between Han and Latin, whether or not you typed the space
  • - Punctuation kept off the start of a line
  • - Chinese emphasis in Kai beside *italic* Latin
  • - A monospace Latin face paired with Source Han Sans, at a calm 1.75 line height

## Wherever a Mac opens files

### Quick Look

Select a Markdown file in Finder and press Space. The preview comes from the same renderer as the editor and its exports, in light and dark.

![Quick Look preview of notes.md in Finder](shots/quicklook-en.webp)

### The `marka` command

```sh
marka notes.md          # open a file
marka notes.md:42       # at line 42
marka .                 # this folder, in the sidebar
git log | marka -       # whatever you pipe in
marka -s README.md      # straight to source mode
```

Install it from **Marka ▸ Install Command Line Tool…** into any folder on your `PATH`.

### The keyboard

An optional Vim mode with Markdown text objects (`i*`, `il`) and word motions that step through Chinese by word. Headings on ⌘1–⌘6, Quick Open on ⌘P, the outline on ⇧⌘O.

### And the rest

  • - Export to HTML, PDF or rich text, set like the editor
  • - Focus on the sentence or paragraph; typewriter scrolling
  • - Tables rendered in place; code highlighted in 17 languages
  • - Paste an image and it is saved in `assets/` next to the document
  • - Light and dark, following your Mac

## Free, then once

  • - **Free, for good:** open, read and edit in source mode, find and replace, the `marka` command, Quick Look.
  • - **Marka Pro:** Live mode, export, Vim, focus and typewriter modes, the folder sidebar, Quick Open and the outline. Free for 14 days, then one purchase: US$24.99 in the US, the App Store's local price elsewhere.

No subscription, no account. Your files stay plain Markdown in your own folders, and Marka collects nothing about you.

## Live 模式，或者源码

Live 模式渲染光标所在块以外的一切，光标所在的块展开成 Markdown 源码。文字不会跳动，也没有另开一栏预览。按 ⌘/，整篇文档立刻变回源码。

> 这一页就是按 Marka 排文档的方式排的。
> 按 ⌘/ 试试，或者点一下任意段落。

## 中文和英文，排在一起

  • - 汉字与西文之间留四分之一个字宽，不管你有没有手打空格
  • - 标点不会出现在行首
  • - 中文强调用楷体，西文用*斜体*
  • - 等宽西文字体配思源黑体，1.75 倍行距，读起来不累

## Mac 上打开文件的地方，都有它

### Quick Look

在访达里选中 Markdown 文件，按空格。预览和编辑器、导出用的是同一套渲染器，明暗模式都支持。

![访达里 notes.md 的 Quick Look 预览](shots/quicklook-zh.webp)

### `marka` 命令

```sh
marka notes.md          # 打开文件
marka notes.md:42       # 跳到第 42 行
marka .                 # 在边栏打开当前文件夹
git log | marka -       # 打开管道输入
marka -s README.md      # 直接进源码模式
```

在 **Marka ▸ 安装命令行工具…** 里选一个 `PATH` 中的文件夹即可。

### 键盘

可选的 Vim 模式，带 Markdown 专用的文本对象（`i*`、`il`），`w`、`b` 能按词在中文里移动。⌘1–⌘6 设标题，⌘P 快速打开，⇧⌘O 看大纲。

### 还有

  • - 导出 HTML、PDF、富文本，排版和编辑器一致
  • - 专注当前句或当前段，打字机滚动
  • - 表格原地渲染，代码高亮支持 17 种语言
  • - 粘贴图片，自动存到文档旁的 `assets/`
  • - 明暗模式跟随系统
