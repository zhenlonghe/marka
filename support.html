# Support

Questions about Marka, answered. Anything else: [zhenlonghe@gmail.com](mailto:zhenlonghe@gmail.com?subject=Marka).

## How does the trial work?

Choose **Start 14-Day Trial** when Marka offers it, or from **Marka ▸ Marka Pro…**. The trial is a free in-app purchase tied to your Apple Account, so it starts once and follows you to your other Macs. When it ends, Marka goes back to the free version. Your documents and settings are not touched.

## I bought Marka Pro, but it is locked on this Mac

Open **Marka ▸ Marka Pro…** and choose **Restore Purchases**. Make sure the App Store is signed in with the Apple Account you bought it with.

## How do I install the command line tool?

Choose **Marka ▸ Install Command Line Tool…** and pick a folder on your `PATH`, such as `/opt/homebrew/bin`. If the folder belongs to the system, for example `/usr/local/bin`, Marka shows a one-line command to run in Terminal instead.

```sh
marka notes.md          # open a file
marka notes.md:42       # at line 42
marka .                 # this folder, in the sidebar
git log | marka -       # whatever you pipe in
marka --help            # every option
```

## Quick Look does not show Markdown previews

Open Marka once after installing it. If the preview still does not appear, check that Marka is turned on in **System Settings ▸ General ▸ Login Items & Extensions ▸ Quick Look**.

## Something else

Write to [zhenlonghe@gmail.com](mailto:zhenlonghe@gmail.com?subject=Marka). It helps to include your Marka and macOS versions (**Marka ▸ About Marka**) and, for a formatting problem, the Markdown that shows it.

# 支持

关于 Marka 的常见问题。其他问题请写信到 [zhenlonghe@gmail.com](mailto:zhenlonghe@gmail.com?subject=Marka)。

## 试用怎么算？

在 Marka 弹出的面板里，或 **Marka ▸ Marka Pro…** 中选择**开始 14 天试用**。试用是一个免费的 App 内购买，记在你的 Apple 账户上，只能开始一次，换一台 Mac 也一样。到期后 Marka 回到免费版，文档和设置都不受影响。

## 买了 Pro，这台 Mac 上却没解锁

打开 **Marka ▸ Marka Pro…**，选择**恢复购买**。请确认 App Store 登录的是购买时用的 Apple 账户。

## 怎么安装命令行工具？

选择 **Marka ▸ 安装命令行工具…**，选一个在 `PATH` 里的文件夹，比如 `/opt/homebrew/bin`。如果文件夹属于系统（比如 `/usr/local/bin`），Marka 会给出一行命令，在终端里执行即可。

```sh
marka notes.md          # 打开文件
marka notes.md:42       # 跳到第 42 行
marka .                 # 在边栏打开当前文件夹
git log | marka -       # 打开管道输入
marka --help            # 查看全部选项
```

## Quick Look 不显示 Markdown 预览

安装后先打开一次 Marka。仍然不显示的话，到**系统设置 ▸ 通用 ▸ 登录项与扩展 ▸ Quick Look** 里确认 Marka 已打开。

## 其他问题

请写信到 [zhenlonghe@gmail.com](mailto:zhenlonghe@gmail.com?subject=Marka)。最好附上 Marka 和 macOS 的版本（**Marka ▸ 关于 Marka**）；排版问题请附上出问题的 Markdown。
